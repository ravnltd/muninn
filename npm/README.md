# muninn-ai

Persistent memory for AI coding agents. 4 MCP tools that compound intelligence across sessions.

```bash
npx muninn-ai
```

Works with Claude Code, Cursor, Windsurf, Continue.dev, and any MCP-compatible tool.

**Full documentation:** [github.com/ravnltd/muninn](https://github.com/ravnltd/muninn)
